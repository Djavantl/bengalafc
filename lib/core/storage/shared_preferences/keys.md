# SharedPreferences keys

| Key | Type | Purpose |
| --- | --- | --- |
| `app.has_completed_onboarding` | bool | Tracks if the initial onboarding was completed. |
| `app.theme_mode` | string | Stores the selected theme mode. |
| `app.language_code` | string | Stores the selected language code. |
| `auth.current_user_id` | string | Stores the current local user id. |
| `fantasy.active_phase_id` | string | Stores the currently selected tournament phase. |
| `fantasy.auto_generate_team_enabled` | bool | Stores whether auto team generation is enabled. |
| `fantasy.max_players_per_national_team` | int | Stores the configured player limit by national team. |
| `scores.refresh_interval_minutes` | int | Stores the score refresh interval. |
| `scores.last_refresh_at` | string | Stores the last score refresh timestamp. |
| `players.last_search_query` | string | Stores the last player search text. |
| `players.filter_national_team_id` | string | Stores the selected national team filter. |
| `players.filter_position` | string | Stores the selected position filter. |
| `players.sort_option` | string | Stores the selected player sort option. |
| `ranking.scope` | string | Stores the selected ranking scope. |
| `ranking.selected_league_id` | string | Stores the selected league ranking id. |
